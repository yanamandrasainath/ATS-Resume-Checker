# ATS Resume Checker

An AI-powered ATS (Applicant Tracking System) Resume Analyzer with Resume Builder built using HTML, CSS, and JavaScript.  
The application helps job seekers analyze their resumes, check ATS compatibility, identify missing skills, and improve their chances of getting shortlisted by recruiters.

## Features

- Upload and analyze resumes
- ATS compatibility score calculation
- Resume keyword matching
- Skill gap analysis
- Identify missing keywords
- Resume improvement suggestions
- Resume Builder
- Create professional resumes using templates
- Download generated resume
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AI-based Resume Analysis Logic
